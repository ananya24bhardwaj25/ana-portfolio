THE RUN

Retrieve, then reason

RADIOThe architecture separates retrieval from reasoning, so the LLM is grounded instead of guessing from memory.

SESSION NOTES

What shipped

An AI-powered fact-checking tool that first retrieves evidence with SentenceTransformers and FAISS, then sends that context to Mistral through Ollama.

  • Semantic evidence retrieval with SentenceTransformers
  • Fast nearest-neighbor search using FAISS
  • Mistral analysis via Ollama
  • Verdicts: Supported, Refuted, Unverifiable — with reasoning
  • Pipeline: claim → embed → retrieve top-k evidence → pass to LLM as context
  • Grounding: the LLM only reasons over retrieved evidence, not free recall
  • Runs fully local: Ollama serves Mistral, no external API calls
