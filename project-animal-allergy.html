THE RUN

The system takes a pet image as input. The vision model classifies the image into one of 37 categories, and the application then uses that result to surface allergy-related guidance.

  • 37-category image classification
  • TinyVGG-inspired CNN for the vision step
  • Data augmentation to make the model more robust to image variation
  • Gemini API used for breed-specific pet-food allergy insights
THE BIG RESULT

The project placed in the top 3 at its hackathon. The useful part is the full flow: image → prediction → understandable allergy guidance.
