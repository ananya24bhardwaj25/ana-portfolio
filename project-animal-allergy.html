SESSION NOTES

What shipped

Created a CNN using a TinyVGG architecture to classify pet images into 37 categories, added data augmentation and deployed through Streamlit.

  • 37-category image-classification target
  • TinyVGG-inspired convolutional architecture
  • Data augmentation to strengthen image learning
  • Gemini API for breed-specific pet-food allergy insights
  • Preprocessing: resize + normalize, class-balanced sampling across the 37 categories
  • Augmentation: random flip, rotation, zoom and colour-jitter to reduce overfitting
  • Output: predicted species/breed passed to Gemini for allergy-relevant food guidance
