THE RUN

Search that reasons like a researcher

RADIOThe hard part was never just "find similar text" — it was making the pagination, follow-ups, and scale hold together once real users started typing.

SESSION NOTES

What shipped

A legal research assistant that takes a natural-language question, retrieves the most relevant judgements with a hybrid semantic + keyword search, then runs them through an LLM-orchestrated pipeline that scores and ranks every candidate before handing back a clean result set — one the user can keep paging through without ever re-running the search.

  • Hybrid retrieval: dense semantic embeddings combined with keyword matching, so exact statute or section references never get lost to pure vector search
  • A LangGraph-orchestrated pipeline scores and ranks every candidate judgement in one pass
  • Stateful pagination — "Find Next 10" pages through the same ranked set instead of re-querying
  • Follow-up awareness: a genuinely new question in the same conversation clears the old ranking and starts fresh, without touching any other open session
  • FastAPI backend behind a React front end
  • Built to scale: old ranking data expires on a rolling window, cleared in small non-locking batches so storage stays flat as usage grows
